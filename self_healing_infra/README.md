# Self-Healing Infrastructure Simulator

An AI-assisted distributed systems simulator capable of:
- monitoring infrastructure health
- detecting cascading failures
- analyzing incidents
- autonomously recovering services

The project models real-world infrastructure reliability concepts including:
- observability
- dependency-aware failures
- autonomous remediation
- AI-assisted operations

# Technologies

- Python
- FastAPI
- OpenAI API
- Streamlit
- Pydantic

# Features

- Distributed service simulation
- Failure injection engine
- Cascading dependency failures
- Monitoring + alert generation
- AI root cause analysis
- Autonomous recovery engine
- Recovery audit logging
- Interactive dashboard

# Example Workflow

1. Inject infrastructure failure
2. Monitoring engine detects outage
3. Alerts generated
4. AI analyzes root cause
5. Self-healing engine executes remediation
6. Services recover automatically
